This file provides the code of R used in Ni et al. This code is intended for transparency and reproducibility and is not able to run.

This project uses data from the Chinese Longitudinal Healthy Longevity Survey (CLHLS), including healthy lifestyle score (composed of smoking, drinking, diet, and physical activity), baseline chronic disease count (0, 1, ≥2), social determinants of health (SDH) score covering five domains (economic stability, education, healthcare access, built environment, social context), and covariates (age, sex, ethnicity, residence, occupation, primary income source) adjusted in the multivariate models.

This project also includes the used data for each figure.
